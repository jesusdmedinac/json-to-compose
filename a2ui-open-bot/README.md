# A2UI Open Bot Playground Samples (`a2ui.open.bot`)

This directory stores benchmark samples generated by Gemini Flash using the **A2UI 1.0 (Agent-to-User Interface)** protocol in CopilotKit's official playground ([a2ui.open.bot](https://a2ui.open.bot/)).

---

## Sample Directory Overview

### 1. `sample-1/saas_dashboard.a2ui`
- **Prompt:** Executive SaaS dashboard for Q3 financial performance (3 KPI stats, AreaChart, DataTable, quick action buttons, and follow-up pill).
- **Format:** **A2UI Express** (Model-optimized DSL).
- **Lines of Code:** **12 lines** (replaces ~1,500 tokens of nested JSON).
- **Components Used:**
  - `Heading` (eyebrow, title, subtitle)
  - `Button` (`Export Report`, `Schedule QBR` with `Event("...")`)
  - `Row` (aligned actions)
  - `Stat` (ARR with +18% trend, Net Retention Rate)
  - `Sparkline` (Active Enterprise Accounts trend)
  - `Grid` (3-column layout)
  - `AreaChart` (NA vs EMEA multi-series stacked)
  - `DataTable` (Enterprise key accounts with columns and status badges)
  - `FollowUp` (interactive suggestion pill)
  - `Column` (root container)

### 2. `sample-2/flight_booking.a2ui` & `flight_booking_wire.jsonl`
- **Prompt:** Interactive flight booking confirmation card from SFO to Tokyo (NRT) with layover timeline, cabin class selector, price breakdown, and confirmation button.
- **Format:** Both **A2UI Express** (`flight_booking.a2ui`, 35 lines) and **Compiled Wire JSON** (`flight_booking_wire.jsonl`).
- **Key Concepts:**
  - Data Binding: `$/booking/cabin` compiles to dynamic state resolution `{"@path": "/cabin"}`.
  - Interactive Action: `pay_btn = Button("Confirm & Pay $1,180", onClick=Event("confirm_booking"))`.
  - Rich Components: `FlightCard`, `Section`, `Timeline`, `SegmentedControl`, `KeyValueList`.

### 3. `sample-3/pricing_comparison.json`
- **Prompt:** 3-tier pricing comparison surface (Hobby, Pro, Enterprise) with monthly/annual switch, badges, feature checkmarks, and CTA buttons.
- **Format:** **Full A2UI 1.0 Wire Protocol** (JSON surface definition with adjacency list).
- **Payload Size:** 9,816 characters.
- **Components Used:**
  - `Switch` (Monthly vs Annual with "20% off" `Badge`)
  - `Grid` of 3 `Card`s (`Hobby`, `Pro` with "Most Popular" `Badge`, `Enterprise`)
  - `ComparisonTable` (feature rows, checkmarks, tier columns)
  - Multiple `Button` CTAs with varying visual variants (`primary`, `outline`)
  - `Callout` (FAQ / clarification note)

## Key Takeaways for `json-to-compose` & `composy`

1. **A2UI Express DSL:** The 12-line Express notation in `sample-1` demonstrates that LLMs can generate complete dashboards with 80% fewer tokens compared to full JSON trees.
2. **Multiplatform Opportunity:** A2UI 1.0 currently targets Web (React). Implementing an `:a2ui-adapter` in `json-to-compose` brings this exact protocol to Jetpack Compose on Android, iOS, Desktop JVM, and Web Wasm.
